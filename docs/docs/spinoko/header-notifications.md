# Header Notifications

The site header can show a notification bell that opens a small popover —
useful for a new bonus alert, a review update, or a site announcement. It's
a fixed set of up to three items you set from settings, not a post type you
publish to.

---

## Setting Up Notifications

Go to **Spinoko &#8594; Notifications**. You get up to three notification
slots, each with:

- Thumbnail image
- Text
- Subtext
- Link

Leave a slot's text empty to skip it — the bell only shows a badge/count for
the slots you've actually filled in, and if none are filled in the bell
doesn't render at all.

The bell itself is the Header Notifications block, already placed in the
default header template part — see [Editing Your Site](/docs/spinoko/site-editor)
if you've removed it and need to add it back.
