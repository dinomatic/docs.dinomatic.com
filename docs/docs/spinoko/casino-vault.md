# Casino Vault

Casino Vault is a search-as-you-type lookup against DinoMatic's remote
casino-data service, so you can pull in a well-known operator's details
instead of typing everything in by hand.

---

## Importing a Casino

1. Go to **Spinoko &#8594; Casino Vault**.
2. Type an operator's name — it's search-only, there's no browsable list
   of the full catalog, so search for a specific casino you already know
   you want.
3. Pick the matching result and import it.

Importing creates a new Casino post and fills in the same fields you'd
otherwise fill in yourself from the Casino Details sidebar — meta (rating,
facts, bonuses), taxonomy terms, and the logo — using the same sanitization
rules as manual entry, so an imported casino is indistinguishable from one
entered by hand. You can edit anything about it afterward.
