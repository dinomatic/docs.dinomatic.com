# Slot Pages

Slots are a separate content type from Casinos, with their own archive
(`/slots/`) and single review template (`/slot/your-slot-name/`). Use them
for individual slot game reviews, distinct from a casino operator review.

---

## Creating a Slot

Go to **Slots &#8594; Add New**. As with Casinos, the write-up goes in the
main editor; the structured data lives in the **Slot Details** sidebar
panel.

### Main Info

Screenshot, name, software provider, slot type, rating (out of 10).

### Pros & Cons

Two free-form lists, same shape as Casino Pages.

### Stats

RTP, volatility, reels, paylines, min/max bet, release date, progressive
jackpot toggle, plus an "advanced fields" section: currencies, languages,
also-land-based toggle, markets, cluster pays, scatter pays, max exposure,
max win per spin, bonus buy, autoplay, quick spin, tumbling reels,
increasing multipliers, orientation, restrictions. These feed the Slot
Specifications block automatically.

### Where to Play

Link the slot to a real Casino from your site (the linked casino), plus
optionally list additional "top casinos" to play it at. This drives both the
Slot Casino Picks sidebar widget and the Slot Where to Play comparison
table.

## Taxonomies

Slots can be tagged with **Slot Types** and **Slot Themes**, both of which
can be bulk-seeded from [Data Import](/docs/spinoko/data-import).

## Displaying Slots

Use the [Slot Card, Slot Listing, Slot Finder, Slot Tile/Slot Tiles, Slot
Specifications, Slot Casino Picks, and Slot Where to Play blocks](/docs/spinoko/blocks)
anywhere you want slots to appear, in addition to the built-in Slot Archive
template.
