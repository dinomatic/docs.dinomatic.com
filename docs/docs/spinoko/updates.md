# Theme Updates

Spinoko updates are baked into the theme, meaning you will receive them in
your WordPress dashboard as soon as they are available and you don't have to
do anything more than just clicking the update button — no need to download
the theme and upload it through FTP again.

This requires an [active license key](/docs/spinoko/license). Without one,
the update check has nothing to authenticate against and no update will be
offered.

If for some reason you want to update manually, you can still download the
latest theme files from your account, remove the old theme directory and
upload the new one to your server.
