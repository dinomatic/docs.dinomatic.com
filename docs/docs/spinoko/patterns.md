# Patterns

Alongside its custom blocks, Spinoko ships a set of ready-made block
**patterns** — pre-built groups of core blocks you can insert and then
customize like normal content. Find them in the block inserter under the
**Spinoko** pattern category.

---

## Available Patterns

| Pattern | What it is |
|---|---|
| Hero Banner (+ v2, v3) | The homepage hero section, in three casino-focused layout variants — matching the Home V1/V2/V3 templates |
| Hero Banner v4, v5 | The slot-focused equivalents of Hero Banner v2 and v3 — a live top-rated slot grid, or a stacked slot-tile ranking — matching the Home V4/V5 templates |
| Verdict | An editorial summary/conclusion box with a score aside, for wrapping up a review |
| Callout Card | An icon + heading + text + CTA card in a theme-tinted box |
| Icon Columns | A three-column icon + heading + text strip |
| Section Header | A section title with optional sub-text and a "see all" link — a starting point you trim down as needed |

Patterns are plain markup once inserted — there's nothing "locked" about
them. Delete a piece you don't need (like Section Header's optional
sub-text) rather than looking for a setting to hide it.
