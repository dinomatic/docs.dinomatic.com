# License Activation

You need to activate your license key to receive new security and feature
updates directly in your WordPress dashboard.

---

## Activating Your Key

1. In your WordPress dashboard, go to **Spinoko** &#8594; the license key
   field is at the top of the main Theme Options page.
2. Paste your product key (from your [DinoMatic account](https://dinomatic.com/account))
   and click activate.
3. The key is validated immediately against DinoMatic's servers — you'll see
   a success or error message right away, before anything is saved.

If activation fails, the message tells you why (invalid key format, the key
is already tied to too many sites, a connection timeout, etc.) rather than a
single generic error.

## Removing a Key

Use the same field to remove/deactivate a key, for example if you're moving
the license to a different site.

## What the Key Unlocks

An active, valid license key is what allows the theme to check for and
install updates from **Dashboard &#8594; Updates**, the same way a
WordPress.org theme does. Without an active key, the theme keeps working —
you just won't be offered new versions.
