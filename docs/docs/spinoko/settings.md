# Theme Options

**Spinoko &#8594; Theme Options** is the main settings screen — everything
that doesn't have a dedicated screen of its own lives here.

---

## License Key

See [License Activation](/docs/spinoko/license).

## Casino Page Options

- **Casino review page slug** — the URL segment single casino reviews are
  published under (e.g. `yoursite.com/{slug}/example-casino`). Changing it
  updates every casino URL immediately.
- **Rich snippet** — toggles Product rich snippet (schema.org) markup on
  casino pages, for Google's star rich result.
- **Rich snippet review author** — who the review is attributed to in that
  markup: the organization (this site) or the review's post author.

## External Link Options

- **External link rel attribute** — the `rel` attribute set on external
  affiliate links. Defaults to `nofollow noopener noreferrer`.
- **External link target attribute** — the `target` attribute set on
  external affiliate links. Defaults to `_blank`.

## Country Support Options

- **Alternatives page** — see [Geo-Targeting](/docs/spinoko/geo-targeting).

## Custom Scripts

- **Header scripts** — pasted as-is near the end of every page's `<head>`
  (analytics, verification meta tags, etc.)
- **Footer scripts** — pasted as-is near the end of every page, just before
  `</body>`.
