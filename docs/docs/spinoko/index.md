# Spinoko Theme

Spinoko is a full-site-editing WordPress theme for casino affiliate and review
publishers. It's built entirely on core WordPress APIs — no third-party field
or page-builder plugin is required to run it.

---

## Getting Started

It's easy to get started with Spinoko. Follow the documentation to install the
theme and build out your site.

### Requirements

Before getting started make sure you have all the requirements met.

To use the theme, you must be running `WordPress 7.1` or higher and `PHP 8.4`
or higher.

Also make sure your host has the minimum requirements to run WordPress and PHP
`max_upload_size` is more than 2MB.

### Demo

You can check out theme demo to get ideas how to build your own website - [Demo](https://spinoko.dinomatic.com).

You can also import the demo directly into your own website with one click
— see [Data Import &#8594; Demo Websites](/docs/spinoko/data-import#demo-websites).

### Dashboard Widget

Once the theme is active, your wp-admin **Dashboard** gets a Spinoko widget
showing your casino/slot publish counts, quick links to Theme Options,
Casino Vault and Integrations, and a list of published casinos still
missing a logo, affiliate link, or bonus.
