# Kemoku Plugin

Kemoku is a WordPress plugin developed for gambling affiliate websites. It gives
opportunities to manage and promote sportsbook and casino reviews easily.

---

## Getting Started

It's easy to get started with Kemoku. Follow the documentation to install the
plugin and create compelling review pages.

### Requirements

Before getting started make sure you have all the requirements met.

To use the plugin, you must be running `WordPress 6.0` or higher and `PHP 8.4`
or higher. \
Recommended `WordPress 7.1`.

Also make sure your host has the minimum requirements to run WordPress and PHP
`max_upload_size` is more than `8MB`.
