# FXT Theme

FXT is a specialized WordPress theme for Forex affiliate websites, built-in
features for broker reviews, comparison tables, listing blocks and more.

---

## Getting Started

It's easy to get started with FXT. Follow the documentations to install the
theme and create compelling websites.

### Requirements

Before getting started make sure you have all the requirements met.

To use the theme, you must be running `WordPress 6.0` or higher and `PHP 8.4` or
higher. Recommended `WordPress 7.1`.

Also make sure your host has the minimum requirements to run WordPress and PHP
`max_upload_size` is more than 8MB.
