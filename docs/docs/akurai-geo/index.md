# AkuraiGeo Plugin

AkuraiGeo is a WordPress plugin developed specifically for Akurai Theme to add
geo targeting functionalities.

---

## Getting Started

It's easy to get started with AkuraiGeo. Follow the documentations to install
the plugin and start using it right away.

### Requirements

Before getting started make sure you have all the requirements met.

To use the plugin, you must be running `WordPress 6.0` or higher and `PHP 8.4`
or higher. Recommended `WordPress 7.1`.

Also make sure your host has the minimum requirements to run WordPress and PHP
`max_upload_size` is more than 2MB.
