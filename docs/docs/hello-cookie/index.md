# Hello Cookie Plugin

Hello Cookie is a simple and lightweight cookie consent notice plugin for
WordPress websites.

---

## Getting Started

It's easy to get started with Hello Cookie. Follow the documentations to install
the plugin and adjust the settings.

### Requirements

Before getting started make sure you have all the requirements met.

To use the plugin, you must be running `WordPress 6.0` and `PHP 8.4` or higher.
Recommended `WordPress 7.1`.
